# Warcraft II для Android

Неофициальный исследовательский проект по запуску Warcraft II на Android.

**Цель:** подготовить Android-сборку с альбомной ориентацией, сенсорным управлением (выбор/приказ касанием и виртуальная мышь), русским интерфейсом и автосохранением.

## Статус

На текущий момент это только начальный репозиторий и документация. Готового Android-приложения, APK и интегрированной игровой сборки здесь пока нет.

- [План проекта](docs/ROADMAP.md)
- [Структура и технический подход](docs/TECHNICAL_APPROACH.md)
- [Игровые данные](game-data/README.md)

## Предполагаемая техническая основа

Рассматривается движок Stratagus и проект Wargus. Wargus преобразует оригинальные ресурсы Warcraft II в формат, используемый Stratagus; это не запуск оригинального `WAR2.EXE` напрямую.

Официальные исходные проекты:
- https://github.com/Wargus/wargus
- https://github.com/drodin/Stratagus

## Игровые данные и права

Оригинальные игровые ресурсы не включены в этот репозиторий. Для локальной сборки пользователь должен иметь законную копию игры. Не публикуйте здесь EXE, архивы данных, музыку, графику или другие защищённые материалы.

## Следующие этапы

1. Проверить совместимость русской редакции ресурсов с актуальным Wargus/wartool.
2. Подготовить Android-проект на базе поддерживаемого порта Stratagus.
3. Реализовать импорт/подготовку игровых данных при первом запуске.
4. Добавить сенсорное управление, виртуальную мышь, альбомную ориентацию и автосохранение.
5. Настроить CI-сборку APK и проверить её на Android 13.

См. документацию в каталоге `docs/`.

# Отчёт о подготовке Android-пакета данных Warcraft II

Дата: 2026-11-20

## Источники

- Ресурсы пользователя: `WarcraftII_Wargus_Resources_Converted.zip` — 952 записи исходного ZIP, 951 файлов данных плюс README (включает маркер data_copied.wargus).
- Скрипты и открытые игровые данные: Wargus v3.3.2, commit `420efb4256574ca2afb995ea3badfea542c416ac`.
- Версия Wargus совпадает с upstream Stratagus v3.3.2, влитым в Android-порт `drodin/Stratagus` в commit `896999504f4d1da9e21900fc16129b73125ef04c`.

## Итоговый архив

Файл: `WarcraftII_Android_Import_Package.zip`

- 1 360 файлов.
- 36 924 202 байта (ZIP).
- SHA-256: `015a9f38d976453e85762cebc44de62df9c215fe950ef95d398265a04c7b0a9b`.
- ZIP test: успешно, ошибок структуры/CRC не обнаружено.
- Присутствуют `scripts/stratagus.lua`, `scripts/wc2-config.lua`, `preferences.lua`, `COPYING`.
- Все 8 карт пользователя включены в парах `.sms.gz` и `.smp.gz`.
- Все 32 активные прямые ссылки `Load(...)` в стартовом `scripts/stratagus.lua` разрешаются на файлы в архиве.
- В стартовом экране убраны только две ссылки на отсутствующие материалы исходного CD: `ui/black_title.png` и `videos/gameintro.ogv`. Сохранены присутствующие `videos/logo.ogv` и `ui/title.png`.
- Добавлен пустой `preferences.lua`, поскольку стартовый сценарий загружает этот пользовательский файл, а в исходном репозитории Wargus он не поставляется.

## Как Android-оболочка использует пакет

В Android-порту проверено:
- Импорт ZIP выполняется через выбор файла и распаковку в приватный каталог приложения.
- Признаком игровых данных является точный путь `scripts/stratagus.lua`.
- Запуск движка передаёт каталог данных через аргумент `-d`.
- Игровая Activity зафиксирована в альбомной ориентации.

## Что пока не доказано

- ZIP структурно согласован по прямым `Load(...)` стартового сценария, но реальный запуск игрового движка и прохождение кампании на устройстве ещё не тестировались.
- Полная русская локализация не подтверждена.
- Полноценное сенсорное управление «выбрать юнит → указать точку» и автосохранение не подтверждены.
- Четыре некорректные записи `MAINDAT.WAR` были пропущены wartool; SMK-видео не перекодированы.
- APK из Android-порта Stratagus — отдельный артефакт движка; не следует считать его проверенной готовой сборкой Warcraft II до успешного импорта и запуска этого архива на Android.

## Следующая проверка

Импортировать архив в Android-приложение, открыть Wargus и проверить стартовое меню, новую игру, звук/музыку, карты и сенсорное управление на реальном устройстве.

# Отчёт о конвертации ресурсов Warcraft II

Дата проверки: 2026-11-20

## Исходник и инструмент

- Входной архив: пользовательская копия Russian SPK DOS CD.
- Конвертер: `wartool V3.3.3`, собранный из Wargus/Stratagus.
- Команда: `wartool -v <каталог DATA> <каталог назначения>`.
- Конвертер определил источник как `Russian SPK DOS CD` и завершился с кодом 0.

## Проверки результата

- 951 извлечённый/преобразованный файл включён в подготовленный архив ресурсов.
- 390 PNG прошли проверку декодирования.
- 506 gzip-файлов успешно распакованы для проверки целостности.
- 18 MIDI-файлов присутствуют.
- 8 исходных PUD-карт преобразованы в пары `.sms.gz` и `.smp.gz` (16 файлов); все пары проверены распаковкой gzip.
- Суммарный размер включённых файлов до ZIP-сжатия: 32,817,986 байт.

## Известные ограничения

- При чтении `MAINDAT.WAR` wartool сообщил о пропуске записей 25, 32, 431 и 437 (некорректная длина/смещение).
- Видеофайлы SMK не удалось декодировать текущим FFmpeg; логотип преобразован в OGV.
- Результат содержит `scripts/wc2-config.lua`, но не содержит `scripts/stratagus.lua`. Это пакет игровых ресурсов, а не полная структура Wargus для непосредственного запуска.
- Русская локализация пока не подтверждена: кодовая страница 866 в конфигурации сама по себе не доказывает полноту перевода.
- Исходные игровые архивы WAR/CUD/SUD не включены в подготовленный ZIP.

## Совместимая версия Wargus — подтверждена

- Android-порт: репозиторий `drodin/Stratagus`, commit `5845d56c67395235c805d6312d464e5700f0b87d`, сообщение `android release v3.3.2-dev1`, 2022-08-11.
- Его непосредственный родительский commit `896999504f4d1da9e21900fc16129b73125ef04c` — merge `v3.3.2` в ветку android.
- Второй родитель этого merge — upstream Stratagus v3.3.2, commit `c57ec097b3563de34ef05c84e6b152f5ab5eaea3`.
- Соответствующий Wargus v3.3.2 tag указывает на commit `420efb4256574ca2afb995ea3badfea542c416ac` (2022-08-10).
- В Wargus v3.3.2 подтверждён файл `scripts/stratagus.lua`; он ожидает сгенерированный `scripts/wc2-config.lua`, который уже присутствует в конвертированных ресурсах.
- Следовательно, выбранный Wargus v3.3.2 совпадает по версии с upstream Stratagus, влитым в Android-порт. Это точное совпадение версии, но ещё не доказательство успешного запуска игры на Android.

## Что подтверждено в Android-оболочке

Проверены исходники Android-ветки `drodin/Stratagus`:

- Экран импорта принимает ZIP и распаковывает его в приватную папку приложения.
- Проверка распаковки ищет точный путь `scripts/stratagus.lua`; без него архив не считается игровыми данными.
- Игровой экран запускает движок с каталогом данных через аргумент `-d`.
- В `AndroidManifest.xml` для игровой Activity задана альбомная ориентация.
- В просмотренном коде оболочки нет подтверждения желаемого управления Warcraft II касанием (выбрать юнит → указать точку) и автосохранения. Эти функции нельзя считать реализованными только на основании наличия Android APK.

## Следующий технический этап

Подготовить полный ZIP для импорта: взять из Wargus v3.3.2 сценарии, кампании, графику и остальные игровые файлы, добавить проверенные конвертированные ресурсы и проверить ссылки/пути. Затем собрать APK и проверить реальный запуск и управление на Android.

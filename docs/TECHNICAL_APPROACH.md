# Технический подход

## Движок

Основной кандидат — Stratagus с Wargus. Wargus предоставляет игровые сценарии и инструменты преобразования ресурсов Warcraft II. Оригинальный исполняемый файл DOS/Windows не является Android-приложением и не предполагается запускать напрямую.

## Подготовка игровых данных

Предполагаемый поток:
1. Пользователь выбирает или импортирует законно принадлежащую ему копию Warcraft II.
2. Конвертер извлекает и преобразует необходимые архивы.
3. Результат помещается в приватное хранилище приложения.
4. При последующих запусках повторная конвертация не требуется, если версия данных не изменилась.

Автоматическая подготовка при первом запуске должна включать проверку целостности, понятные сообщения об ошибках и возможность повторить импорт.

## Android-интеграция

Нужна Android-оболочка для запуска Stratagus, управление жизненным циклом Activity, полноэкранный альбомный режим, ввод касаний и виртуальный указатель. Детали API и сборки будут зафиксированы после выбора конкретной версии порта.

## Русский язык

Нужно проверить, как выбранная версия движка обрабатывает русскую кодировку и шрифты. Нельзя считать русификацию готовой только потому, что в исходном архиве присутствует файл строк.

## Лицензии

Перед включением исходников и зависимостей необходимо проверить их лицензии. Оригинальные игровые данные Warcraft II не должны попадать в публичный репозиторий или CI-артефакты без соответствующих прав.

# Игровые данные

Этот каталог предназначен для документации по локальному импорту игровых ресурсов.

Оригинальные игровые файлы Warcraft II намеренно не хранятся в GitHub. Не загружайте сюда `.WAR`, `.CUD`, `.SUD`, `.EXE`, музыку, изображения или другие ресурсы коммерческой игры.

Пользовательская копия игры должна импортироваться локально в приложении или в отдельный защищённый каталог сборочной среды. Конвертированные файлы также не следует публиковать без проверки прав.
